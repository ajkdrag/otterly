# Bundled fonts

These fonts load from the app bundle, including when offline. Each family is distributed under the SIL Open Font License 1.1. Its license is included beside the font files.

Downloaded from the official Google Fonts repository on 2026-09-28:

- [Inter](https://github.com/google/fonts/tree/main/ofl/inter): regular and italic variable fonts, weights 100–900, retained for existing themes. The original filenames use `[opsz,wght]` instead of `-Variable`.
- [IBM Plex Sans](https://github.com/google/fonts/tree/main/ofl/ibmplexsans): regular and italic variable fonts, weights 100–700. The original filenames use `[wdth,wght]` instead of `-Variable`.
- [IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono): regular, italic and bold.
- [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk): variable font, weights 300–700. The original filename uses `[wght]` instead of `-Variable`.

Font binaries are unchanged. The variable files were renamed for simple asset URLs. Existing themes and saved font choices still resolve through the theme settings.
