Otterly View on GitHub

Your notes, in a folder you own.

Otterly is a desktop app for Markdown notes. Open a folder, write what you need, and find it again later. Your files stay on your computer.

Download Otterly macOS, Windows, and Linux
See it in action 44 seconds

Write without setup

Headings, lists, code, images, and a clean editor are ready when you open a folder.

Find your way back

Search your notes, follow wiki links, and see which notes link to each other.

Keep your files

Every note is a Markdown file. You can open the same folder with other tools.

Free and open source. No account needed.
